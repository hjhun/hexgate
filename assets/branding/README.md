# Hexgate portal artwork

`hexgate-portal-v1.png` was generated with the built-in image generation tool. It is an original illustration requested by the user, inspired by the fantasy-engineered blue-energy gate idea behind the app name. No Riot/League logo, game screenshot, extracted texture or character asset is included. This is design provenance, not a trademark clearance claim for public distribution.

Prompt used:

Create a beautiful production-quality Android launcher icon concept for an app called Hexgate. The user named this SSH app after the Hexgates in League of Legends and wants that evocative hextech teleportation gate feeling. ORIGINAL artwork inspired by that fantasy-engineering visual language: a bold hexagonal bronze-gold mechanical portal, glowing electric azure/cyan crystalline energy inside, a sense of stepping through a magical gate to a distant computer. Not a generic terminal logo: NO chevron prompt, NO underscore, NO lettering. Single emblem, straight-on with subtle dimensional bevels, elegant engineered gold segments and restrained carved angular details, deep midnight blue background. Portal center is a luminous blue aperture with nested hexagonal light contours receding toward a brilliant small core, conveying connection and travel. Distinct readable silhouette at 48 pixels, strong weight, controlled blue bloom, luxurious gold versus blue contrast. Fantasy game UI polish but simplified for a real mobile launcher icon; avoid tiny gears, busy runes, excessive particles and muddy textures. One square 1024x1024 full-bleed artwork; no mockup, no contact sheet, no text, no watermark, no Riot/League logo. Keep main emblem entirely inside centered 65 percent adaptive icon safe area. Dark background extends edge to edge without an outer rounded-square border. Hero composition with breathing room.

The generated output is preserved as delivered; Android resources control its displayed size. `ic_launcher_portal.xml` insets the artwork for adaptive launcher masks. The earlier mint terminal concept was not selected. Runtime package uses a copy under app/src/main/res/drawable-nodpi/.

## Selected launcher artwork

The user approved `hexgate-terminal-v3.png`: gold hexagon, blue gate interior and white `>_`. The original bytes are copied to `app/src/main/res/drawable-nodpi/hexgate_portal.png` for launcher and workspace branding. Earlier candidates above are retained as design history.
