# Terminal icon candidate v2

User feedback: previous gold/blue portal was too game-like. Simplify it and add the terminal prompt >_. Generated with the built-in image tool, saved unchanged. Preview candidate only pending user review; not yet substituted into the existing v0.1.1 APK.

Prompt:

Design a single extremely clean, restrained professional Android SSH terminal app icon for Hexgate. The prior concept was an ornate golden fantasy teleportation portal and the user rejected it as too game-like. This new direction must be radically simpler and clearly a developer tool. One bold thin-to-medium weight geometric hexagonal gate outline in muted warm champagne gold, a small deliberate gap at the right edge. Inside the gate place a highly legible TERMINAL PROMPT: one right-facing chevron > followed by a short horizontal UNDERSCORE cursor _, both in pale electric cyan. The chevron and underscore must read together as >_ centered in the hexagon. Solid uniform midnight navy background #0B1420, edge to edge. Flat vector-logo quality, precise straight lines, controlled proportions and generous negative space. Palette ONLY midnight navy, muted gold, and pale cyan. No texture, no glow, no energy vortex, no gemstones, no gears, no runes, no fantasy ornament, no bevels, no 3D, no shadows, no gradients, no text other than the >_ symbol, no watermark. Single coherent simple emblem, crisp at tiny launcher sizes. Main symbol within central 60 percent square for adaptive icon masks. A single square icon artwork, not an option sheet, not a device mockup. The feeling is a quiet technical gateway into a remote terminal, with only the faint geometric memory of a hexgate.
